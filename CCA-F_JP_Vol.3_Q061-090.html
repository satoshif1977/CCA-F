Q61 Claude Code configuration and workflows

Q62 Prompt engineering and structured output
不動産ポータルで has_pool・has_gym 等のboolean フィールドを設定→言及がない場合に false と設定してしまい「存在しない」か「不明」か区別できない。
❓ 3つの状態（存在する・存在しない・不明）を正確に捉えるスキーマ修正は？
✅ 正解
フィールドを enum 制約（[PRESENT", "ABSENT", "UNKNOWN"] など）を持つ文字列として再定義する。
enum を使用することで、2値論理（boolean）の制約を打破し、モデルに対して「不明」という選択肢を構造レベルで明示的に提示できるため、勝手な false 設定（ハルシネーション）を効果的に抑制できます。
💡 暗記ポイント
booleanは2値しか持てず、言及がない場合に補完バイアスで false と判定されやすい。
文字列enumで「PRESENT」「ABSENT」「UNKNOWN」の3つのラベルを定義するのが最も確実な設計。
