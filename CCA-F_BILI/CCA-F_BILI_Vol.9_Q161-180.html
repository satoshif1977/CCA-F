Q161API usage and best practices
🇯🇵 Japanese
200万件の過去医療記録からデータ抽出にMessage Batches APIを使用予定。構文解析エラーの発見が遅れると膨大な損失になる。どうリスクを軽減すべきか？
✓ 正解
プロンプトを改善し、構造化出力のフォーマットを検証するために、同期APIを通じて代表的なサンプルセットを実行する。
💡 暗記ポイント
大規模バッチ（Message Batches API）は非同期・最大24時間かかるため、プロンプト/スキーマ設計の失敗は全件の無駄になる。必ず：①小さなサンプル（数百件）でリアルタイムAPIを使ったパイロット検証→②バリデーション確認→③本番バッチ投入の順で進める。
🇺🇸 English
A team plans to use the Message Batches API to extract data from 2 million historical medical records. Delayed discovery of parsing errors would cause enormous losses. How should this risk be mitigated?
✓ Correct Answer
Run a representative sample set through the synchronous API first to validate the prompt and structured output format before submitting the full batch.
🔑 Key Words
pilot validationパイロット検証本番バッチ投入前に同期 API で少量サンプルを実行してプロンプト・スキーマを検証する手順

🇯🇵 Japanese

✓ 正解

💡 暗記ポイント

🇺🇸 English
A financial audit agent receives 50 pages of transaction logs as a single large prompt. It processes the beginning and end correctly but misses information in the middle. What is this phenomenon called and how should it be addressed?
✓ Correct Answer
Place a summary of expected key findings at the top of the input and organize the detailed transaction logs using clear, distinct section headers.
🔑 Key Words

Q165Agent architecture and orchestration
🇯🇵 Japanese
企業沿革史作成のマルチエージェントシステムで、時間軸（創業期・成長期・成熟期）でサブエージェントに分割処理させたが、全期間を貫く横断的なテーマ（企業理念の変遷等）が失われた。解決策は？
✓ 正解
オーケストレーターの時間的な分割が限定的すぎた。時間による分割に加えて、全期間を通じて「経営理念の変遷」を追跡する役割を設けるなど、テーマ別のスコープでも分割を行うべきであった。
💡 暗記ポイント
時間軸（垂直）のみでタスクを分割すると、全期間にわたる横断的（水平）文脈が失われる。解決策：時間軸分割に加えて「特定テーマ横断エージェント」（企業理念専門・製品戦略専門等）を並置する組み合わせ設計が効果的。
🇺🇸 English
A multi-agent system for creating a corporate history splits sub-agents by time period (founding, growth, maturity), but cross-cutting themes like corporate philosophy evolution are lost. What was the architectural mistake?
✓ Correct Answer
The orchestrator's temporal division was too limiting. In addition to time-based splits, thematic scope divisions — such as a dedicated agent tracking corporate philosophy across all periods — should also be added.
🔑 Key Words
temporal vs thematic decomposition時間軸 vs テーマ別分解時間軸（垂直）のみでなくテーマ横断（水平）の分割を組み合わせる設計
cross-cutting theme横断的テーマ複数の時間軸・領域にまたがるテーマ。時間軸分割のみでは失われやすい
thematic agentテーマ専門エージェント特定のテーマ（企業理念・製品戦略等）を全期間にわたって追跡する専門エージェント
combined decomposition※ 関連概念組み合わせ分解時間軸分割 × テーマ別分割を組み合わせた多次元のタスク分解設計
vertical vs horizontal split※ 関連概念垂直 vs 水平分割時間・フェーズで分割（垂直）とテーマ・機能で分割（水平）の組み合わせ

🇺🇸 English

✓ Correct Answer
Use Message Batches API for regular news updates to achieve 50% cost reduction, and use the real-time Messages API for breaking news to meet the 5-minute latency requirement.
