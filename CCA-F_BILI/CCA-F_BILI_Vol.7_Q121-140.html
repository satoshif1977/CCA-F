Launch individual sub-agents for each region to analyze specific regulatory flows, have each return a summarized profile, and inject only those summaries into the main agent's context.

🇯🇵 Japanese
医療診断ラボが一般健診(全体の98%)で98%精度を達成。稀な遺伝子検査(全体の2%)も同様に高精度と判断した。何が問題か？
✓ 正解

💡 暗記ポイント
不均衡データ問題：多数派クラスの高精度は少数派クラスの精度を保証しない。重要な少数派（稀な疾患等）は個別に評価指標（F1スコア・適合率・再現率）を測定する必要がある。全体精度のみを指標にすると重大な見落としが生じる。
🇺🇸 English
A medical diagnostic lab achieves 98% accuracy on general health screenings (98% of volume) and assumes its rare genetic tests (2% of volume) are similarly accurate. What is the problem and how should it be addressed?
✓ Correct Answer
Separately isolate the rare genetic test segment and independently measure field-level accuracy using a statistically significant sample to verify it meets business requirements.
🔑 Key Words
class imbalance※ 関連概念クラス不均衡多数派クラスの高精度が少数派クラスの精度を保証しない問題
stratified evaluation層化評価サブグループ別に独立して精度を評価すること。全体精度では少数派の問題が隠れる
rare case accuracy稀なケースの精度全体精度とは独立して、稀なケースの精度を個別測定する必要性

🇯🇵 Japanese

✓ 正解

🇺🇸 English
A scientific paper auto-review pipeline has three phases — literature review, methodology evaluation, and final recommendation. Keeping all conversation history in one context causes 'context corruption'. What is the solution?
✓ Correct Answer
Use a main orchestrator agent to launch a Phase 1 sub-agent that returns a concise summary of its findings, which the orchestrator then uses as the sole input context for launching the Phase 2 sub-agent.
🔑 Key Words

A specific prompt or task identifier — such as 'SafetyLogExtractionV2' — so that Few-shot sets are built only from examples relevant to the target task.

✓ 正解
サブエージェント内で指数バックオフによる再試行メカニズムを実装し、すべての再試行を使い果たした場合にのみ、クエリの詳細を含む構造化エラーを伝播させる。
💡 暗記ポイント
一時的な障害（Transient failure）への最適な対処は指数バックオフ（Exponential Backoff）付きリトライ。即時リトライは503をさらに増やすだけ。間隔を指数的に延ばしながら（1秒→2秒→4秒）最大リトライ回数を設定する。
🇺🇸 English
A medical diagnosis support agent receives 503 Service Unavailable responses due to a temporary rate limit while querying an external medical literature database. What is the optimal error handling strategy?
✓ Correct Answer
Implement an exponential backoff retry mechanism within the sub-agent, propagating a structured error with query details only after all retries are exhausted.
🔑 Key Words
exponential backoff指数バックオフリトライ間隔を指数的に延ばす戦略（1秒→2秒→4秒）。503 等の一時的障害に最適
transient failure一時的な障害レート制限・ネットワーク瞬断等の短期間で解消する障害。即時リトライは逆効果
retry exhaustionリトライ枯渇最大リトライ回数を使い果たした後のみ構造化エラーを上位に伝播させる設計
